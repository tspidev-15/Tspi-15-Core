
# TSPI-15 Syntax

TSPI-15 is an experimental programming language.
Its syntax is still under development.

## Variables

Draft syntax:

```tspi
variable name = "Alex"
```

## Output

Draft syntax:

```tspi
show "Hello, world!"
show name
```

## Status

- Syntax: experimental
- Interpreter: not implemented
- Examples: drafts for design purposes
